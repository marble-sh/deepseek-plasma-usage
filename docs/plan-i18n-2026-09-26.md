## 2. Verified facts (observed this session — level 1)

- **String inventory:** `xgettext` over `contents/**/*.{qml,js}` with the KDE
  keyword set (`-ki18n:1 -ki18nc:1c,2 -ki18np:1,2 -ki18ncp:1c,2,3`) yields
  **70 entries**: 69 unique msgids, of which **4 carry `msgctxt`** and
  **4 are plural forms**. All live in QML (`contents/ui/*.qml`); the `js/`
  modules are pure logic and contain no translatable strings.
- **Domain:** `plasma_applet_` + the metadata plugin id →
  `plasma_applet_org.deepseek.plasma.usage`. Confirmed by the 3477
  `plasma_applet_*.mo` files in `/usr/share/locale/*/LC_MESSAGES/` and by
  `Plasma::Applet::translationDomain()` / `plasma_applet_` in `libPlasma.so.6.7.5`.
- **Lookup path — empirically proven, not assumed.** A probe catalog containing
  only `Balance`/`Today`/`Tokens` was compiled to
  `contents/locale/es_CL/LC_MESSAGES/plasma_applet_org.deepseek.plasma.usage.mo`,
  installed, and rendered with `QT_QPA_PLATFORM=xcb LANG=es_CL.UTF-8
LANGUAGE=es_CL plasmawindowed …`: the probe values appeared while the
  untranslated strings stayed English. So the in-package `contents/locale` path
  works in Plasma 6.7.5 and no system-wide install is needed.
- **Tools present:** `xgettext`, `msgfmt`, `msgcat`, `msgmerge` (gettext).
- **Only `es_CL` is a generated system locale** here (`locale -a` has 6 entries),
  which is why the probe used it. Qt resolves `LANG` without needing a generated
  locale, but only `es_CL` can be _rendered_ end-to-end on this machine; other
  locales will be verified by `msgfmt --check` + `msgunfmt` diff instead.

## 3. Phases

- **P1 — Disambiguate the ambiguous strings (small source edit).** Short column
  headers (`In`, `Out`, `Cost`, `Cached`, `Requests`, `Save`, `Clear`) are
  ambiguous to a translator without context, and gettext keys are global. Add
  `msgctxt` to those calls, then re-extract `translate/template.pot`.
  Existing behaviour is unchanged; only the catalog keys change.
- **P2 — Tooling.** Commit `translate/template.pot`, a `translate/` helper
  (`merge.sh` to re-extract, `build.sh` to compile `.po` → `.mo` into
  `contents/locale/`) adapted from the KDE l10n-scripty conventions the
  reference plasmoid uses, plus `translate/LINGUAS`.
- **P3 — Author 12 catalogs.** `translate/<locale>.po` for each requested
  locale, with correct `Plural-Forms` per language (see §5), translated by me.
- **P4 — Compile + ship.** `msgfmt` each catalog into
  `contents/locale/<locale>/LC_MESSAGES/plasma_applet_org.deepseek.plasma.usage.mo`
  and **track the `.mo` files in git** (the reference plasmoid does exactly this,
  so a clone → `./install.sh` works with no gettext, and `--pack` yields a
  complete archive). Also teach `install.sh` to refresh them when `msgfmt`
  exists and to warn (not fail) when it does not.
- **P5 — Verify.** `msgfmt --check -v` on all 12; `msgunfmt` round-trip diff
  against each `.po`; assert every msgid is non-empty in every catalog
  (a scripted completeness check); `./install.sh`; `plasmawindowed` render for
  `es_CL` (the only renderable locale) and a second locale forced via
  `LANGUAGE`; `node --test` + `qmllint` unchanged and still green.
- **P6 — Docs + commit.** README i18n section, `docs/decisions-log.md` entry,
  `.gitignore` for `translate/infiles.list`, and a single commit.

## 5. Risks / notes

- **Plural forms differ per language** and gettext fails silently-ish if wrong:
  zh_CN `nplurals=1; plural=0`, id_ID `1; 0`, hi_IN `2; (n != 1)`,
  fr_FR `2; (n > 1)`, ru_RU/ru_BY `3; (n%10==1 && n%100!=11 ? 0 : …)`,
  es_* `2; (n != 1)`, en_IN `2; (n != 1)`. The widget only uses plurals for
  "Last %1 day(s)", "%1 minute(s) ago", "%1 hour(s) ago" and the panel-metric
  label — four entries, but ru's three-form rule must be right.
- **Russian is the tricky one**: the `%1`/`%2` placeholders must survive in all
  three plural variants and the case after a numeral differs. I will keep the
  numeral and noun adjacent and re-check each variant.
- **Translations are mine, not a native speaker's.** They will be linguistically
  careful but unreviewed; a native review pass is a sensible follow-up before
  publishing (see open decision 3).
- **`msgfmt` is a build-time, not runtime, dependency** — D6 (zero runtime deps)
  is preserved, and shipping the `.mo` means even the build dep is optional.
- **Do not touch the rotated secrets or KWallet** in this task.

## 6. Open decisions (each with a default I will take unless told otherwise)

1. **Base-language fallback catalogs.** Qt's lookup for `es_CL` tries `es_CL`
   then **`es`**, and there is no bare `es` on this system (KDE ships `es_ES`,
   `es_419`, … but no plain `es`). So a user with generic `es` gets English.
   _Default:_ ship the 12 requested catalogs **plus** bare-language aliases
   `ru`, `fr`, `id`, `hi` (= the single regional variant) and `es_419`
   (KDE's Latin-America code). ~6 extra tiny files. _Alternatives:_ exactly the
   12 requested; or add bare `es` as an alias of `es_ES`.
2. **`en_IN` is identical to the source English.** _Default:_ ship it anyway, so
   the locale resolves explicitly and the catalog is ready for future divergence.
3. **Native review.** _Default:_ I translate and mark the catalogs as
   unreviewed (`# Unreviewed translation — needs a native speaker pass`), and we
   treat hi/ru/zh as the priority for review.
4. **`msgctxt` on ambiguous short strings (P1).** _Default:_ yes — do the P1
   edit. _Alternative:_ skip it, and the headers stay ambiguous to translators.
5. **Track the compiled `.mo` files.** _Default:_ yes (reference-plasmoid
   convention; keeps `./install.sh` working without gettext).
6. **Translate `metadata.json` `Name`/`Description`** (`Name[zh_CN]` …), which is
   what the "Add Widgets" browser shows. _Default:_ yes, same 12 locales.
7. **Spanish variants.** _Default:_ `es_ES` gets Spain forms (`ordenador`-style
   vocabulary where it differs) and all four LA catalogs share Latin-American
   forms, with genuine per-country wording only where it actually differs
   (e.g. `es_AR`/`es_CU` "computadora" vs `es_ES` "ordenador"). They will be
   near-identical files; that is correct, not laziness. _Alternative:_ one
   shared LA catalog copied four times with no country tweaks.
