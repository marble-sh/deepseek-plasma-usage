# Code of conduct

## The short version

Be decent. This project has an issue tracker, and that is all the infrastructure
there is: no mailing list, no chat, no meetings. Treat the tracker like a room with
other people in it.

Concretely, that means:

- Assume the person you are replying to is acting in good faith.
- Critique the code, the number, or the translation — not the person.
- Do not derail someone's issue with an unrelated argument.
- No harassment, slurs, sexualised attention, or attacks on anyone's identity.
- English is not everyone's first language here, and neither is shell or QML.
  Answer the question that was asked.

Being told to stop means stopping.

## Scope

This applies to the repository's issues, pull requests, discussions and commit
messages — wherever the project is the context. It does not govern how anyone
behaves elsewhere.

## Reporting

Message the maintainer ([@marble-sh](https://github.com/marble-sh)) privately
through GitHub, or use
[the private reporting form](https://github.com/marble-sh/deepseek-plasma-usage/security/advisories/new)
if you would rather not use a normal message. Reports are read by the maintainer
alone.

Depending on what happened, the response may be a private word, editing or deleting
a comment, locking an issue, or blocking an account from the repository.

## Attribution

This is a deliberately short, purpose-written policy rather than the
[Contributor Covenant](https://www.contributor-covenant.org/), which would be four
